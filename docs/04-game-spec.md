# 04. 게임 사양서

구현(`src/game/*`, `components/BugSquash.tsx`)의 실제 값을 정리한 문서입니다. 좌표 단위는 논리 픽셀(480×270 기준), 시간은 초입니다.

## 1. 조작

| 동작 | 키 | 비고 |
|---|---|---|
| 좌 이동 | `←` `A` | |
| 우 이동 | `→` `D` | |
| 점프 | `Space` `C` | 짧게 누르면 낮은 점프 |
| 공격 | `Z` `X` `J` | |
| 들어가기 / 조사 | `↑` `W` `E` | 인터랙터블 위에서만 |
| 아래 | `↓` `S` | `↓` + 점프 = 발판에서 내려가기 |
| 소리 on/off | `M` | (게임 시작 후) |
| 오버레이 닫기 | `Esc` | |

- `Ctrl` / `Meta` / `Alt` 조합 입력은 무시한다 (브라우저 단축키 보호).
- 오버레이가 열려 있는 동안 게임 입력은 비활성화된다 (`Esc`·BUG SQUASH 키는 해당 UI가 처리).
- 터치: `◀` `▶` `↑` `⚔`(공격) `⤒`(점프) 버튼.

## 2. 플레이어

### 2.1 이동·물리

| 항목 | 값 |
|---|---|
| 중력 | 950 px/s² |
| 최대 낙하 속도 | 480 px/s |
| 달리기 속도 | 112 px/s |
| 가속 | 지상 1100 / 공중 700 px/s² |
| 점프 초속 | 330 px/s (위쪽) |
| 점프 단축 | 점프 키를 떼면 상승 속도를 −130으로 제한 |
| 점프 입력 선행 | 0.12초 (착지 직전에 눌러도 점프) |
| 코요테 타임 | 0.09초 (발판에서 떨어진 직후에도 점프 가능) |
| 아래 점프(내려가기) | 0.22초 동안 발판 충돌 무시 |
| 이동 범위 | x: 8 ~ (씬 폭 − 8) |
| 착지 판정 | 위에서 아래로 내려올 때 발판 윗면과 교차하면 착지. 폭 ±4 |

### 2.2 공격

| 항목 | 값 |
|---|---|
| 재사용 대기 | 0.34초 |
| 동작 시간 | 0.30초 (참격 이펙트는 진행률 0.12~0.95 구간) |
| 판정 시간 | 시작 후 0.07 ~ 0.20초 |
| 판정 범위 | 정면 30 × 26 (플레이어 발 기준 위로 28 ~ 2) |
| 다단 히트 | 1회 휘두름당 적 1체에 1회만 |
| 공격 중 이동 | 지상에서 속도 ×0.45, 방향 전환 불가 |
| 공중 공격 | 가능 |
| 데미지 | `1 + floor((레벨 − 1) / 3)` |

### 2.3 체력·피격

| 항목 | 값 |
|---|---|
| 초기 체력 | 5 (최대 8까지 증가) |
| 피격 | 슬라임과 접촉(좌우 ±11, 높이 겹침) 시 −1 |
| 무적 시간 | 1.2초 (점멸) |
| 넉백 | 가로 150 / 세로 −170 (공격 동작은 취소) |
| KO | 체력 0 → 0.7초 후 전환 연출 → **같은 씬의 시작 위치**에서 체력 전회복·무적 1.5초로 부활 |
| 페널티 | 없음 (코인·경험치 유지) |

### 2.4 성장

| 항목 | 값 |
|---|---|
| 경험치 획득 | 슬라임 1체당 12 |
| 필요 경험치 | Lv1→2: 30, 이후 직전 값 ×1.5 (반올림) |
| 레벨업 시 | 체력 전회복, 짝수 레벨에서 최대 체력 +1 (상한 8), 효과음/배너/파티클 |
| 초기값 | Lv 1, EXP 0 |

> 진행 상황(레벨·코인·체력)은 **새로고침하면 초기화**된다.

## 3. 적

### 3.1 슬라임 (`slime`)

| 항목 | 값 |
|---|---|
| 체력 | 3 |
| 크기 | 약 16×12 (히트 판정은 폭 18) |
| 행동 | 지상에서 일정 간격(0.9~1.8초)으로 점프 이동. 홈 위치 ±range 안에서 배회 |
| 추적 | 플레이어가 100px 이내, 높이 차 30 이내이면 간격 0.55초로 접근 (속도 62, 평소 38) |
| 점프 | 세로 −150 |
| 피격 | 넉백(가로 130, 세로 −130), 0.22초 흰색 점멸. 히트스톱 0.05초, 화면 흔들림 0.12초 |
| 처치 | 파티클 14개, 코인 1~3개 드롭(각 1코인), 경험치 12 |
| 재출현 | 12초 후, 플레이어가 홈 위치에서 160px 넘게 떨어져 있을 때 |

### 3.2 허수아비 (`dummy`)

체력 무한(9999). 쓰러지지 않고, 맞으면 흔들리며 데미지 숫자를 표시한다. 길드에만 있다.

## 7. BUG SQUASH

| 항목 | 값 |
|---|---|
| 제한 시간 | 20초 (시작 전 3초 카운트다운) |
| 구멍 | 3×3 = 9 (동시에 여러 마리 출현) |
| 입력 | 클릭/탭, 또는 `Q W E / A S D / Z X C` (숫자패드 7-8-9/4-5-6/1-2-3 대응) |
| 시작/재도전 | `Enter` (대기·결과 화면에서는 `Space` 도 가능) |

### 7.1 출현

| 항목 | 규칙 |
|---|---|
| 첫 출현 | 시작 0.4초 후 |
| 출현 간격 | `max(0.28, 0.75 − 경과초 × 0.025)` |
| 종류 확률 | 황금 14% / 폭탄 20% / 일반 66% |
| 노출 시간 | `max(0.45, 기본 − 경과초 × 0.025)` (기본: 황금 0.65, 그 외 1.15) |
| 빈 구멍 | 비어 있는 구멍 중에서 무작위 |

### 7.2 점수

| 대상 | 점수 |
|---|---|
| 일반 버그 | +1 × 배율 |
| 황금 버그 | +5 × 배율 |
| 폭탄 | −3 (0 미만 불가), 콤보 초기화, 화면 흔들림 + 붉은 번쩍임 |
| 콤보 | 버그/황금을 연속으로 잡을 때마다 +1. **5 이상 ×2, 10 이상 ×3** |
| 콤보 끊김 | 폭탄을 건드리거나, 일반/황금 버그를 놓쳤을 때 (폭탄을 놓치는 것은 무관) |

### 7.3 결과·보상

| 항목 | 규칙 |
|---|---|
| 보상 코인 | `floor(점수 / 2)` + 신기록이면 +5 |
| 신기록 조건 | 점수 > 이전 최고 기록 이고 점수 > 0 |
| 코인 반영 | 결과 확정 시 본 게임 코인에 합산 |
| 기록 저장 | `localStorage` 키 `pixel-village:bugsquash-best` (접근 불가 환경에서는 저장 생략) |

## 8. 사운드

| 효과음 | 발생 시점 |
|---|---|
| jump / attack / hit / kill | 점프 / 공격 휘두름 / 적 타격 / 적 처치 |
| coin | 코인 획득, 황금 버그 |
| hurt | 피격 |
| enter | 건물 출입 |
| levelup | 레벨업, BUG SQUASH 종료 |

| squash / bomb | 버그 타격 / 폭탄 |
