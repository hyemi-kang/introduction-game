# 03. 화면 설계서

## 1. 화면 구성 개요

단일 페이지(`/`) 안에서 **게임 화면(Canvas) + 겹쳐지는 UI**로 구성된다. 페이지 이동은 없다.

```
┌──────────────────────────────────────────────┐
│ [HUD 좌: LV·♥·EXP]                [코인][🔊][?] │  ← HUD (React, 절대 위치)
│            ┌──────────────┐                    │
│            │ 씬 이름 배너  │                    │  ← Banner (씬 진입/레벨업)
│            └──────────────┘                    │
│                                                │
│            Canvas (480×270 → 확대 표시)         │  ← 게임 월드
│                                                │
│                              [조작 가이드]      │  ← ControlHint (우하단, 조작하면 소멸)
│              [ ↑ 라벨 ]                        │  ← Prompt (문/오브젝트 앞)
│ [◀][▶]                      [↑][⚔][⤒]         │  ← TouchControls (터치 기기만)
└──────────────────────────────────────────────┘
        + 오버레이(Overlay): 화면 전체를 덮는 창
```

## 4. 공통 UI

### 4.1 HUD (`Hud`)

| 위치 | 요소 | 동작 |
|---|---|---|
| 좌상 | 레벨 배지 / 하트(최대 체력 수만큼) / 경험치 바 | 피격 시 하트 흔들림, 회복 시 팝, EXP는 8단계 `steps` 로 증가 |
| 우상 | 코인 패널 | 증가 시 숫자 팝 |
| 우상 | 소리 버튼 (도트 스피커 아이콘) | 클릭 또는 `M`. 꺼지면 빨간 ✕ 표시 |
| 우상 | `?` 버튼 | 조작법 오버레이 |

### 4.2 Banner / Prompt / ControlHint

| 요소 | 동작 |
|---|---|
| Banner | 씬 진입(`HEMI VILLAGE`, `MY HOME` …)·`LEVEL UP!  Lv.N` 을 좌→우 슬라이드로 표시 후 퇴장 |
| Prompt | 인터랙터블 위에 서면 하단에 `[↑] 라벨` 표시. 떠나면 페이드 아웃 |
| ControlHint | 우하단에 이동/점프/공격/들어가기를 반투명하게 표시. 이동·점프·공격 키나 클릭이 있으면 페이드 아웃 (터치 기기에서는 표시 안 함) |
| 인터랙터블 화살표 | 월드 위에서 상하로 흔들리는 `↑`. 가까이 가면 색이 진해짐 |

### 4.3 Overlay (공통 창)

- 타이틀 바(`▶ 제목`) + `✕ ESC` 버튼. `Esc` / 바깥 클릭 / 버튼으로 닫힘.
- 열림: 0.55초 `back.out` 스케일+이동+회전. 닫힘: 0.28초 역방향.
- 창 높이는 화면의 92% 이내이며 내용은 스크롤.

## 5. 오버레이 화면 상세

### O-01/O-02 프로필 (`ProfilePanel`)

- 탭: **STATUS / SKILLS**.
- STATUS: 캐릭터 아바타(대기 모션·가끔 공격), `Lv.` + 직함, 연락처 링크 3종, 이름·별명, 소속·위치, 자기소개(타이프라이터), 능력치 4종(STR/DEX/INT/LUK 바), 기본 정보 4행.
- SKILLS: 3개 카테고리 카드, 항목별 5칸 숙련도.

### O-03 발자취 지도 (`JourneyMap`)

- 양피지 지도(SVG 800×420) 위에 **경력 6지점**(2019 → NOW)을 잇는 길.
- 재생: 시작 지점 등장 → 주인공 마커가 길을 따라 이동하며 **발자국이 24px 간격으로 좌/우 번갈아 찍힘** → 지점 도착 시 아이콘이 elastic으로 등장하고 링이 퍼짐 → 하단 카드에 연도·제목·설명 표시 → 마지막에 마커가 깡충.
- 재생 중 `SKIP ▶▶`, 완료 후 `↻ REPLAY`. 완료 후엔 각 지점을 클릭해 설명을 다시 볼 수 있다.
- 지도 높이는 `max-h-[44vh]` 로 제한해 하단 카드가 잘리지 않게 한다.

### O-04 퀘스트 게시판 (`GuildBoard`, `QuestShots`)

| 상태 | 내용 |
|---|---|
| 목록 | 코르크 보드에 종이 6장. 각 종이: 랭크(S/A/B/C)·상태 도장(CLEAR / IN PROGRESS)·**썸네일**·제목·요약 1줄·태그 3개. 핀과 살짝 기울어진 각도 |
| 진입 연출 | 종이가 위에서 `bounce.out` 으로 떨어지며 핀이 박힘, 간판이 늘어지며 등장 |
| 호버 | 종이가 떠오르며 똑바로 선다 |
| 상세 | 클릭한 종이 위치에서 중앙으로 확대. 다른 종이는 흐려짐. 제목·기간·역할·상태·요약·**이미지 갤러리**·세부 항목·태그·링크 버튼 |
| 갤러리 | ◀ ▶ / 키보드 ← → / 점으로 이동. 캡션 표시. 클릭하면 화면 전체 확대(닫기 버튼, 바깥 클릭, `Esc` 는 확대만 닫음) |
| 이미지 | `shots[].src` 가 있으면 실제 이미지, 없거나 로드 실패 시 도트풍 **SAMPLE 화면** |
| 닫기 | `← 돌아가기` 로 종이 위치로 축소 복귀 |

### O-05 BUG SQUASH (`BugSquash`)

| 단계 | 화면 |
|---|---|
| 대기 | 규칙 설명(+1 / 황금 +5 / 폭탄 −3), 키 안내, BEST, `START (Enter)` |
| 카운트다운 | 3 → 2 → 1 |
| 플레이 | 3×3 구멍 (키 Q W E / A S D / Z X C 라벨 표시). 상단에 SCORE·COMBO·TIME, 시간 바 |
| 결과 | `TIME UP!` 점수, 신기록 표시(깜빡임), 획득 코인, BEST, `RETRY` / `나가기` |

폭탄 타격 시 화면이 흔들리고 붉게 번쩍인다.

### O-06 조작법

`ControlHint.CONTROLS` 의 5행(이동/점프/공격/들어가기/소리)을 표로 표시하고, 슬라임 처치·문 조작 안내 문구를 덧붙인다.

## 6. 반응형·입력

| 항목 | 내용 |
|---|---|
| 화면 크기 | 비율 16:9 유지. 창이 좁거나 낮으면 축소 |
| 오버레이 | 폭 `min(지정px, 94~96vw)`, 높이 최대 92vh, 내부 스크롤 |
| 터치 기기 (`pointer: coarse`) | 좌하단 `◀ ▶`, 우하단 `↑ ⚔ ⤒` 버튼 표시. ControlHint는 숨김 |
| 마우스 | 오버레이 내 클릭 조작, BUG SQUASH는 클릭/탭으로 타격 |

## 7. 시각 스타일 가이드 (현행)

| 항목 | 규칙 |
|---|---|
| 월드 그래픽 | 4px 블록, 윤곽선 없음, 채도 높은 단색. 주인공=거북이(1칸 3px), 슬라임=8×6 도트(1칸 2px) |
| 주인공 색 | 등껍질 `#44b04b`/`#2f8f3d`, 피부 `#8fcf3f`, 배 `#6aa82e`, 눈 `#111` |
| 큰 창 | 하늘색 계열 배경·크림색 테두리·둥근 모서리의 버튼 (별도 세션에서 조정한 스타일) |
| HUD | 각진 계단형 테두리 (`.pxl-*`) |
| 폰트 | Galmuri(도트). 못 불러오면 `monospace` |
