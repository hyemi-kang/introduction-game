# 08. 미해결 사항·과제

현행 구현을 정리하면서 확인된 **미해결 사항**과 **남은 과제**입니다. 신규 기능의 결정이 아니라, 판단이 필요한 항목의 목록입니다.

## 1. 공개 전 확인 (필수)

| No | 항목 | 내용 | 담당 |
|---|---|---|---|
| P-1 | 개인정보 | `src/data/profile.ts` 가 전부 **가짜 데이터** (이름·메일·URL·경력). 실제 정보로 교체하고 공개 범위를 확인 | 소유자 |
| P-2 | GitHub URL | 한식 소개 페이지의 링크 `https://github.com/your-id/hansik-introduction` 은 플레이스홀더 | 소유자 |
| P-3 | 스크린샷 | 퀘스트 이미지는 모두 SAMPLE 화면. 실제 스크린샷을 `public/quests/` 에 두고 `shots[].src` 지정 | 소유자 |
| P-4 | 경력 6건 | 발자취 지도는 항목 수 6 고정. 실제 경력이 6건이 아니면 `NODES` 도 수정 | 소유자/개발 |
