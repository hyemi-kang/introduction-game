# 01. 요건정의서

| 항목 | 내용 |
|---|---|
| 문서 상태 | 현행 구현 기준 (AS-IS) |
| 기준일 | 2026-10-08 |
| 대상 | introduction-game (PIXEL VILLAGE) |

## 1. 배경과 목적

### 1.1 배경
일반적인 문서형 자기소개/포트폴리오는 인상이 남기 어렵다. 소개 내용을 **게임 월드를 탐험하면서 발견**하게 만들어, 개발자(프론트엔드/애니메이션)로서의 기술력과 개성을 함께 전달한다.

### 1.2 목적
- 방문자가 캐릭터를 조작해 마을을 돌아다니며 **프로필 / 경력 / 프로젝트**를 확인할 수 있게 한다.
- 점프·공격·미니게임 등 **진짜 게임 같은 조작감**으로 체류 경험을 만든다.
- React / Next.js / TypeScript / Tailwind / GSAP 활용 능력과 **애니메이션 연출 역량**을 보여준다.

### 1.3 성공 기준
- 첫 방문자가 별도 설명 없이 이동 → 건물 진입 → 정보 열람까지 도달할 수 있다.
- 모든 소개 콘텐츠(프로필·스킬·경력·프로젝트)를 게임 안에서 열람할 수 있다.

## 2. 용어

| 용어 | 의미 |
|---|---|
| 마을 (village) | 게임 내 야외 맵. 3개 건물이 있는 횡스크롤 월드 |
| 홈 (HOME) | **게임 내 "집"**(실내 씬). 사이트의 메인 페이지가 아님 |
| 길드 (GUILD) | 프로젝트 소개용 실내 씬. 퀘스트 게시판이 있음 |
| 아케이드 (ARCADE) | 미니게임용 실내 씬 |
| 씬 (scene) | 마을·홈·길드·아케이드의 각 장면 |
| 오버레이 | 게임 화면 위에 열리는 정보 창 (프로필·지도 등) |
| 퀘스트 | 길드 게시판의 종이 1장 = 프로젝트 1건 |
| 인터랙터블 | 문·지도·책장 등 ↑ 키로 조작하는 오브젝트 |

## 3. 범위

### 3.1 범위 내
- 2D 횡스크롤 월드와 캐릭터 조작 (이동·점프·공격)
- 4개 씬: 마을 / 홈 / 길드 / 아케이드
- 정보 열람 UI 4종: 프로필(STATUS)·스킬(SKILLS)·발자취 지도·퀘스트 게시판
- 전투 요소: 슬라임(적), 코인, 경험치/레벨, 체력
- 미니게임 1종: BUG SQUASH
- 효과음/BGM, 화면 전환 연출, 터치 조작

### 3.2 범위 외 (현재 구현하지 않음)
- 서버/DB, 회원 기능, 문의 폼, 다국어 전환 UI
- 진행 상황 저장(코인·레벨·위치는 새로고침 시 초기화)
- 멀티플레이, 랭킹(서버 연동)
- 외부 이미지/음원 에셋
- 게임패드 입력
- 자동화 테스트 코드(단위/E2E) — 수동·임시 검증만 실시

## 4. 이해관계자

| 역할 | 설명 |
|---|---|
| 소유자 | 본인 포트폴리오로 사용하는 개발자 (콘텐츠 작성·갱신) |

## 5. 기능 요건

우선도: **M**=필수(구현 완료) / **S**=권장(구현 완료)

### 5.1 월드·조작

| ID | 요건 | 우선도 | 비고 |
|---|---|---|---|
| FR-101 | 캐릭터를 좌우로 이동할 수 있다 | M | ← → / A D |
| FR-102 | 점프할 수 있다. 키를 짧게 누르면 낮게 뛴다 | M | Space / C |
| FR-103 | 공격할 수 있다. 공중에서도 가능하다 | M | Z / X / J |
| FR-104 | 떠 있는 발판에 올라갈 수 있고, 아래키+점프로 내려올 수 있다 | M | |
| FR-105 | 문·오브젝트 앞에서 ↑ (또는 E / W)로 조작한다 | M | 조작 가능 위치에 화살표/안내 표시 |
| FR-106 | 마을은 카메라가 캐릭터를 따라 횡스크롤하고, 원경은 시차(parallax)로 움직인다 | M | |
| FR-107 | 첫 화면에서 즉시 게임이 시작된다 (타이틀/시작 버튼 없음) | M | 조작 힌트가 우하단에 표시되고 조작하면 사라진다 |

### 5.2 전투·성장

| ID | 요건 | 우선도 |
|---|---|---|
| FR-201 | 마을에 적(슬라임)이 있고 공격으로 쓰러뜨릴 수 있다 | M |
| FR-202 | 적에게 닿으면 체력이 줄고 일시 무적이 된다. 체력 0이면 KO 후 씬 시작 지점에서 부활한다 | M |
| FR-203 | 적을 쓰러뜨리면 코인과 경험치를 얻고, 경험치가 차면 레벨업한다 | M |
| FR-204 | 마을에 코인이 배치되어 있고, 접근하면 흡수된다 | M |
| FR-205 | 길드의 허수아비를 공격하면 데미지 숫자가 표시된다 (쓰러지지 않음) | S |
| FR-206 | 체력·레벨·경험치·코인을 HUD에 항상 표시한다 | M |

### 5.3 씬·건물

| ID | 요건 | 우선도 |
|---|---|---|
| FR-301 | 마을에서 HOME / GUILD / ARCADE 건물 문으로 들어갈 수 있다 | M |
| FR-302 | 각 실내에는 EXIT 문이 있고, 나가면 마을의 해당 건물 앞으로 돌아온다 | M |

|---|---|---|---|

## 7. 제약·전제

- 실행 환경: Node.js 22 이상 / npm 10 이상 (개발 환경: Windows 11)
- 사내 네트워크에서 npm 레지스트리 접속 시 SSL 인증서 오류가 발생할 수 있다 (→ [07](07-dev-guide.md))
- 논리 해상도는 **480×270 고정**. 캔버스의 모든 좌표는 이 기준
- 콘텐츠 언어는 한국어(UI 문구 포함). 다국어화는 범위 외

## 8. 수용 기준 (요약)

1. 페이지를 열면 타이틀 없이 마을에서 즉시 조작할 수 있다.
2. 이동·점프·공격이 동작하고, 슬라임 처치로 코인과 경험치가 증가한다.
3. 홈에 들어가면 프로필이 자동으로 열리고, 닫은 뒤에도 홈에 머문다.
4. 홈의 지도에서 발자취 애니메이션이 재생되고 마지막 지점에서 REPLAY가 표시된다.
5. 길드 게시판에서 종이를 선택하면 확대되고, 이미지 갤러리와 GitHub 링크가 표시된다.
6. 아케이드에서 BUG SQUASH를 끝까지 플레이하면 결과와 획득 코인이 표시되고 HUD 코인에 합산된다.
7. `npm run build` 와 `npx tsc --noEmit` 이 오류 없이 완료된다.

상세한 테스트 항목은 [06 테스트 사양서](06-test-spec.md)를 참조.
