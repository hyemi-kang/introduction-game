## 3. 회귀 확인 포인트 (수정할 때 특히 주의)

1. **오버레이 닫은 직후 EXIT 오작동** (`interactLock`) — T-206
2. **폰트 대기로 인한 시작 지연, 외부 요청의 재유입** — T-001/T-002
3. **BUG SQUASH 대기·결과 화면의 색 대비** — T-409
4. **퀘스트 확대 창(Lightbox)** 이 종이의 `transform` 에 갇히는 문제 — `createPortal(document.body)` 유지 (T-309)
5. **개발 서버에서 `.next` 충돌**: 다른 `next dev` 가 켜져 있는 상태에서 `next build` 를 실행하지 않는다
